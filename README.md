### Ссылка → формат → файл

Пришлите ссылку на публикацию, выберите качество или формат и получите файл в том же чате.

## Возможности

| Формат | Возможности |
| :--- | :--- |
| **Видео** | Выбор разрешения или лучшего качества |
| **Аудио** | Извлечение MP3 |
| **Фото** | Обложки видео и фотоальбомы TikTok |
| **GIF** | Конвертация роликов до 30 секунд |
| **Субтитры** | Обычные и автоматически созданные |
| **Плейлисты** | Добавление видео в очередь с лимитом |
| **Оформление** | Rich Messages с превью, чек-листами и таблицами, цветные кнопки, анимированные премиум-эмодзи, эффекты сообщений |

**YouTube · TikTok · Instagram · X / Twitter · Vimeo · Reddit**

И другие источники, поддерживаемые yt-dlp. Доступность зависит от сайта и прав доступа к публикации.

В личном чате доступен выбор формата. В группах бот скачивает автоматически, с ориентиром на 720p.

<details>
<summary><strong>Команды</strong></summary>

| Команда | Действие |
| :--- | :--- |
| `/start` | Главное меню |
| `/help` | Инструкция и лимиты |
| `/status` | Текущие загрузки |
| `/cancel` | Отмена проверки ссылки и загрузок до отправки |
| `/stats` | Личная статистика |
| `/admin` | Управление ботом |
| `/broadcast` | Рассылка с подтверждением и остановкой |
| `/stats_global` | Общая статистика |

Последние три команды доступны администраторам в личном чате.

**Рассылка** получает всех, кто хоть раз писал боту и не заблокировал его.

- Пост любого типа: текст, медиа, стикер, голосовое или альбом до 10 файлов.
- Перед отправкой — точная копия. Можно добавить кнопки-ссылки, эффект 🎉🔥❤️👍 и отправку без звука.
- Живой прогресс: доставлено, заблокировали, скорость, сколько осталось. Паузы Telegram бот выдерживает сам.
- Прогресс хранится в базе: после перезапуска бот предложит продолжить, без повторной отправки.
- «Отозвать у всех» удаляет пост у получателей (Telegram разрешает в течение 48 часов).
- Те, кто заблокировал бота, автоматически исключаются из следующих рассылок.

</details>

## Запуск на сервере

**Нужны:** Docker с Compose. Хватает 4 ГБ RAM и ~9 ГБ диска.

```bash
git clone https://github.com/ReNothingg/ReSave.git
cd ReSave
cp .env.example .env
```

Заполните в `.env` `BOT_TOKEN`, `ADMIN_IDS`, `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`
(последние два — на [my.telegram.org/apps](https://my.telegram.org/apps)), затем:

```bash
docker compose up -d --build
```

Поднимутся два контейнера: бот и локальный Telegram Bot API (файлы до 2 ГБ).
Оба перезапускаются сами после падения и после перезагрузки сервера.

| Действие | Команда |
| :--- | :--- |
| Логи | `docker compose logs -f --tail 100 bot` |
| Перезапуск | `docker compose restart bot` |
| Обновление кода | `git pull && docker compose up -d --build` |
| Загрузить cookies | `docker compose cp cookies.txt bot:/data/cookies.txt` |

## Надёжность

- Каждая загрузка и проверка ссылки идёт в отдельном процессе. Зависший yt-dlp
  убивается по таймауту или при отсутствии прогресса и не блокирует очередь.
- yt-dlp, yt-dlp-ejs и gallery-dl обновляются сами каждые несколько часов,
  без перезапуска бота: сайты часто ломают старые версии.
- Если не получилось в выбранном качестве, бот пробует качество ниже и любой доступный формат.
- Перед загрузкой и во время неё проверяется свободное место на диске.
- Временные файлы чистятся каждые 30 минут.
- Если бот зависнет целиком, он сам завершится, и Docker его перезапустит.

## Настройки

Все параметры — в [`.env.example`](.env.example).

| Параметр | Назначение |
| :--- | :--- |
| `ADMIN_IDS` | ID администраторов через запятую |
| `MAX_CONCURRENT_DOWNLOADS` | Параллельные загрузки · **1** для сервера на 4 ГБ |
| `MAX_TASKS_PER_USER` | Задачи одного пользователя |
| `MAX_PLAYLIST_ITEMS` | Видео из одного плейлиста · **25** |
| `MAX_FILE_SIZE` | Максимальный размер файла в байтах |
| `MIN_FREE_DISK_MB` | Сколько места оставлять свободным · **512** |
| `DOWNLOAD_STALL_TIMEOUT_SECONDS` | Через сколько секунд без прогресса загрузка прерывается |
| `TOOLS_AUTO_UPDATE` | Автообновление yt-dlp и gallery-dl |

<details>
<summary><strong>Cookies и хранение данных</strong></summary>

- Cookies в формате Netscape — `cookies.txt`. Бот использует временные копии.
- Статистика — `database.db` (SQLite).
- Данные бота в Docker лежат в томе `bot-data` (`/data` внутри контейнера).
- Очередь и меню хранятся в памяти: после перезапуска незавершённые запросы нужно отправить снова.

</details>

<details>
<summary><strong>Для разработки</strong></summary>

Оформление включено по умолчанию: `RICH_MESSAGES_ENABLED=true`, `CUSTOM_EMOJI_ENABLED=true`.
Эмодзи взяты из набора Telegram Topics и проверены как анимированные.
Для их использования нужен Premium у владельца бота либо дополнительный username с Fragment.
Если API отклоняет эмодзи, бот сохраняет Rich Messages и цветные кнопки, заменяя иконки на обычные.
Для API без Rich Messages предусмотрено HTML-оформление.

Локальный запуск на тестовом боте (нужны Python 3.11+, FFmpeg и Deno):

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt ruff
```

Создайте `.env.local` — его значения важнее `.env`, а в git он не попадает:

```env
BOT_TOKEN=токен_тестового_бота
BOT_API_BASE_URL=
STATS_DB_PATH=local.db
TEMP_DIR=temp_local
```

```bash
.venv/bin/python main.py
.venv/bin/ruff check .
```

Без локального Bot API лимит файла — 50 МБ.

| Путь | Ответственность |
| :--- | :--- |
| `main.py` | Запуск и сборка сервисов |
| `src/handlers/` | Команды, меню и административные действия |
| `src/core/` | Очередь, скачивание, обработка и отправка |
| `src/core/ytdlp_worker.py` | Изолированный процесс yt-dlp |
| `src/utils/` | Форматирование текста и работа с файлами |


</details>
