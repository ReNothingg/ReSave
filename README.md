## О проекте

ReSave — это удобный Telegram-бот, предназначенный для скачивания видео и другого медиаконтента из интернета. Он разработан с учетом потребностей как обычных пользователей, так и начинающих программистов, желающих понять, как работают подобные сервисы. Бот использует мощь библиотеки `yt-dlp` для извлечения контента с различных платформ, обеспечивая высокую скорость и надежность загрузки.

## Что умеет бот

*   **Скачивание видео:** Загружайте видео по ссылке с популярных платформ, таких как YouTube, Vimeo и многих других, благодаря интеграции с `yt-dlp`.
*   **Inline-режим:** Отправляйте ссылки прямо из поля ввода сообщений Telegram, не переключаясь между приложениями.
*   **Работа в группах:** Используйте бота в групповых чатах для совместного скачивания контента.
*   **Фоновая загрузка:** Бот может загружать файлы в фоновом режиме и уведомлять вас по завершении.
*   **Управление очередью:** Для предотвращения перегрузки и обеспечения справедливого распределения ресурсов, бот использует систему очереди и устанавливает ограничения на количество одновременных загрузок для каждого пользователя.
*   **Статистика и миграция данных:** Бот ведет статистику использования в SQLite базе данных и автоматически мигрирует данные из старого формата `user_stats.json`, если он существует.
*   **Админские команды:** Предусмотрены специальные команды для администраторов для управления ботом и просмотра статистики.

## Быстрый старт для начинающих

Этот раздел поможет вам быстро установить и запустить бота, даже если вы только начинаете свой путь в программировании.

### Шаг 1: Установка зависимостей

Прежде всего, вам нужно установить все необходимые библиотеки Python. Откройте терминал или командную строку, перейдите в директорию проекта и выполните команду:

```bash
pip install -r requirements.txt
```

Эта команда прочитает файл `requirements.txt` и установит все библиотеки, которые нужны для работы бота.

### Шаг 2: Настройка файла `.env`

Для работы бота требуется ваш уникальный токен Telegram-бота и, возможно, другие настройки.

1.  Найдите файл с названием `.env.example` в корневой директории проекта.
2.  Скопируйте его и переименуйте копию в `.env`.
3.  Откройте файл `.env` в любом текстовом редакторе.
4.  Заполните следующие поля:
    *   `BOT_TOKEN`: Получите токен вашего бота у [@BotFather](https://t.me/botfather) в Telegram и вставьте его сюда.
    *   `ADMIN_IDS`: Укажите ваш ID в Telegram (или ID других администраторов через запятую), чтобы вы могли использовать админские команды. Чтобы узнать свой ID, можно воспользоваться ботом [@userinfobot](https://t.me/userinfobot).
    *   `VIP_USERS`: Здесь можно указать ID пользователей, которым предоставляются особые привилегии (например, увеличенные лимиты).

**Пример `.env` файла:**

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ1234567890
ADMIN_IDS=987654321
VIP_USERS=
```

### Шаг 3: Отправка файлов большего размера (опционально)

Telegram имеет ограничение на размер файлов, которые можно отправлять через Bot API (обычно около 50 MB). Если вы хотите скачивать и отправлять файлы размером до 2 GB, вам понадобится локальный сервер `telegram-bot-api`.

#### Вариант А: Запуск локального `telegram-bot-api` через Docker

Docker — это удобный инструмент для запуска приложений в изолированных контейнерах.

1.  **Установите Docker:** Если у вас еще нет Docker, скачайте и установите его с официального сайта: [https://www.docker.com/get-started](https://www.docker.com/get-started)
2.  **Запустите `telegram-bot-api`:** В терминале, находясь в директории проекта, выполните:

    ```bash
    docker compose up -d telegram-bot-api
    ```
    Эта команда скачает образ `telegram-bot-api` (если его нет) и запустит его в фоновом режиме.
3.  **Просмотр логов (если нужно):** Чтобы увидеть, как работает `telegram-bot-api`, выполните:

    ```bash
    docker compose logs -f telegram-bot-api
    ```
4.  **Настройка `.env` для Docker:** В вашем `.env` файле добавьте следующие строки:

    ```env
    BOT_API_BASE_URL=http://127.0.0.1:8081
    BOT_API_IS_LOCAL=true
    MAX_FILE_SIZE=2097152000
    SEND_AS_DOC_LIMIT=2097152000
    TELEGRAM_API_ID=ваш_api_id
    TELEGRAM_API_HASH=ваш_api_hash
    ```
    *   `BOT_API_BASE_URL`: Адрес, по которому бот будет обращаться к локальному `telegram-bot-api`.
    *   `MAX_FILE_SIZE` и `SEND_AS_DOC_LIMIT`: Устанавливают максимальный размер файла, который бот может обрабатывать. Значение `2097152000` соответствует примерно 2 GB.
    *   `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`: Эти данные нужны для работы `telegram-bot-api`. Получить их можно на [https://my.telegram.org/apps](https://my.telegram.org/apps), создав новое приложение.

#### Вариант Б: Запуск локального `telegram-bot-api` без Docker (для продвинутых)

Если вы предпочитаете не использовать Docker, вы можете установить `telegram-bot-api` вручную. Этот вариант более сложный и требует сборки бинарного файла.

1.  **Сборка бинарника:** На Mac или Linux вы можете собрать бинарник для Linux с помощью скрипта в репозитории:

    ```bash
    bash scripts/build_telegram_bot_api_linux_amd64.sh
    ```
    Готовый файл появится в директории `dist/`.
2.  **Загрузка на сервер:** Загрузите собранный бинарник на ваш сервер (например, с помощью `scp`) и сделайте его исполняемым:

    ```bash
    scp dist/telegram-bot-api-linux-amd64 ваш_пользователь@ваш_сервер:/путь/к/директории/telegram-bot-api
    ssh ваш_пользователь@ваш_сервер 'chmod +x /путь/к/директории/telegram-bot-api'
    ```
3.  **Настройка `.env`:** В вашем `.env` файле укажите:

    ```env
    BOT_TOKEN=ваш_токен_бота
    ADMIN_IDS=123456789
    VIP_USERS=
    TELEGRAM_API_ID=ваш_api_id
    TELEGRAM_API_HASH=ваш_api_hash
    MAX_FILE_SIZE=2097152000
    SEND_AS_DOC_LIMIT=2097152000
    MAX_CONCURRENT_DOWNLOADS=1
    MAX_DOWNLOADS_PER_USER=1
    INLINE_DOWNLOAD_ENABLED=false
    INLINE_DOWNLOAD_TIMEOUT=120
    ```
4.  **Запуск через systemd-сервис:** Для автоматического запуска `telegram-bot-api` вместе с ботом на сервере (например, `alwaysdata`) используйте скрипт `scripts/run_alwaysdata_local_bot_api.sh`. Убедитесь, что путь к бинарнику в скрипте соответствует вашему расположению.

### Шаг 4: Запуск бота

После выполнения всех предыдущих шагов, вы можете запустить бота. В терминале, находясь в директории проекта, выполните:

```bash
python main.py
```

Теперь ваш бот должен быть онлайн и готов принимать команды!

### Cookies для `yt-dlp` (опционально)

Если вы хотите скачивать контент с платформ, требующих авторизации (например, некоторые закрытые плейлисты или видео), вам нужно будет предоставить `yt-dlp` файл с cookies.

1.  Создайте файл `cookies.txt` в корневой директории проекта.
2.  Экспортируйте ваши cookies из браузера (например, с помощью расширения для браузера) и вставьте их в этот файл в формате Netscape.

## Как это работает (для начинающих)

Давайте разберемся, как ReSave обрабатывает ваши запросы.

1.  **Получение ссылки:** Когда вы отправляете боту ссылку, он получает ее через Telegram Bot API.
2.  **Обработка `yt-dlp`:** Бот передает эту ссылку библиотеке `yt-dlp`. `yt-dlp` — это очень мощный инструмент, который умеет находить и скачивать видео с сотен сайтов. Он анализирует ссылку, определяет тип контента и находит лучшие доступные форматы (разрешение, аудиодорожки).
3.  **Управление загрузкой:**
    *   **Очередь:** Если бот уже занят другими загрузками или вы превысили лимит одновременных загрузок, ваша ссылка будет добавлена в очередь.
    *   **Лимиты:** Бот следит за тем, чтобы один пользователь не запускал слишком много загрузок одновременно.
4.  **Скачивание файла:** `yt-dlp` скачивает видео в временную директорию (`temp_downloads/`).
5.  **Отправка файла:** После завершения загрузки, бот отправляет файл обратно вам через Telegram.
    *   **Большие файлы:** Если файл больше 50 MB, и вы настроили локальный `telegram-bot-api`, бот использует его для отправки файла. Это позволяет отправлять файлы размером до 2 GB.
    *   **Маленькие файлы:** Файлы меньшего размера отправляются напрямую через стандартный Telegram Bot API.
6.  **Статистика:** Каждая успешная загрузка записывается в базу данных SQLite для ведения статистики.

## Устранение неполадок

*   **Бот не отвечает на команды:**
    *   Убедитесь, что токен вашего бота (`BOT_TOKEN`) указан правильно в `.env` файле.
    *   Проверьте, что бот запущен (`python main.py`).
    *   Перезапустите бота.

*   **Файлы не отправляются или отправляются с ошибкой:**
    *   Если вы пытаетесь отправить файлы больше 50 MB, убедитесь, что локальный `telegram-bot-api` запущен и правильно настроен в `.env` файле.
    *   Проверьте, что `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` указаны верно.
    *   Убедитесь, что у вас достаточно места на диске для временных файлов.

*   **`yt-dlp` не может скачать видео:**
    *   Возможно, сайт изменил свою структуру, и `yt-dlp` нуждается в обновлении. Попробуйте обновить `yt-dlp`: `pip install --upgrade yt-dlp`.
    *   Для некоторых сайтов могут потребоваться cookies (см. раздел "Cookies для `yt-dlp`").

*   **Ошибки при запуске:**
    *   Убедитесь, что вы установили все зависимости (`pip install -r requirements.txt`).
    *   Проверьте, что все переменные окружения в `.env` файле заполнены корректно.

## Структура проекта

*   `main.py`: Точка входа в приложение. Здесь инициализируется бот и запускается его основной цикл.
*   `src/`: Содержит основную логику бота: обработчики команд, работу с Telegram API, взаимодействие с `yt-dlp`, управление очередью и базой данных.
*   `tests/`: Здесь находятся автоматические тесты для проверки работоспособности различных частей бота.
*   `temp_downloads/`: Временная директория, где хранятся скачиваемые файлы перед отправкой.
*   `cookies.txt`: Файл для хранения cookies, если требуется авторизация для скачивания.
*   `database.db`: SQLite база данных, используемая для хранения статистики и другой информации.
*   `bot.log`: Файл для записи логов работы бота.

## Запуск как systemd-сервис (Linux)

Для автоматического запуска и управления ботом на сервере Linux, вы можете использовать `systemd`.

1.  **Создайте файл сервиса:** Создайте файл `/etc/systemd/system/resave.service` со следующим содержимым (адаптируйте пути под вашу систему):

    ```ini
    [Unit]
    Description=ReSave Telegram Bot
    After=network.target

    [Service]
    User=ваш_пользователь
    WorkingDirectory=/путь/к/директории/ReSave
    ExecStart=/usr/bin/python3 /путь/к/директории/ReSave/main.py
    Restart=always
    RestartSec=10

    [Install]
    WantedBy=multi-user.target
    ```
2.  **Управление сервисом:**
    *   Запуск: `sudo systemctl start resave`
    *   Проверка статуса: `sudo systemctl status resave`
    *   Перезапуск: `sudo systemctl restart resave`
    *   Включение автозапуска при старте системы: `sudo systemctl enable resave`
    *   Просмотр логов: `journalctl -u resave -f`
